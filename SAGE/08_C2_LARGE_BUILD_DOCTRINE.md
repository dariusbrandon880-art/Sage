# SAGE C2 Large-Build Operating Doctrine

Status: Architecture doctrine candidate for governed promotion

Purpose:
Define how SAGE coordinates larger capability campaigns without changing authority boundaries.

## C2 Loop

SENSE → RECON → SUPER SEARCH → BOUND → DECIDE → AUTHORIZE → BUILD → OBSERVE → VERIFY → COMPOUND

Rules:

- Repository truth and validated evidence are primary.
- External intelligence is not canonical truth.
- Closed findings are preserved and not unnecessarily rebuilt.
- Authorization precedes mutation.
- Verification precedes promotion.

## Large-Build Model

Large builds increase capability aperture, not risk tolerance.

A single bounded capability frontier may be examined through five reach extensions:

1. Architecture Capability
2. Evidence Verification
3. Research Intelligence
4. Cognitive Continuity
5. Adversarial Reality

These are not independent agents or authorities. They reconverge into validated capability.

## Cognitive Architecture Placement

The Brain Tree is a cognitive substrate, not an execution authority.

Flow:

Research Graph
→ Evidence Evaluation
→ Cognitive State
→ Decision Object
→ Authorization Boundary
→ Execution
→ Observation
→ Learning Candidate
→ Verification
→ Validated Evolution

## Permanent Separations

- Observation is not learning.
- Learning candidate is not truth.
- Recommendation is not authorization.
- Implementation is not capability proof.
- Passing tests alone is not complete evidence.

## Rolls-Royce + Lamborghini Principle

Rolls-Royce constraints:
- provenance
- continuity
- safety
- evidence integrity
- verification

Lamborghini acceleration:
- parallel investigation
- capability composition
- larger bounded campaigns
- faster iteration

Equation:

Higher velocity = larger aperture + same governance

## Promotion Rule

Only validated state enters Master Archive.
Research candidates remain candidates until verified.
