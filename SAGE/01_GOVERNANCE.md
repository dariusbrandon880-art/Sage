# SAGE GOVERNANCE RULES

## SOURCE-OF-TRUTH RULE

Always establish:
ACTUAL origin/main
→ ACTUAL ancestry
→ ACTUAL worktree
→ ACTUAL code
→ ACTUAL tests
→ ACTUAL runtime/evidence

Never substitute:
* PR descriptions;
* conversational memory;
* stale Drive state;
* agent claims;
* expected test counts.

## CANONICAL EXECUTION LOOP

DISCOVER
→ BOUND
→ EXPERIMENT
→ EXECUTE
→ VERIFY
→ DEPLOY
→ OBSERVE
→ COMPOUND

## PROPOSAL NON-EXECUTION LAW

AI-generated proposals remain inert until authorized.

No agent may invent:
* authorization;
* authority;
* state transitions;
* protected-state mutations.

## CONTINUITY RULE

A new Gemini session must recover state from the projection rather than assuming a blank project.
