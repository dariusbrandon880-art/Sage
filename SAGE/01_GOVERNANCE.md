# SAGE GOVERNANCE RULES

## SOURCE-OF-TRUTH RULE

Always establish:
ACTUAL origin/main
→ ACTUAL ancestry
→ ACTUAL worktree
→ ACTUAL code
→ ACTUAL tests
→ ACTUAL runtime/evidence

Never substitute:
* PR descriptions;
* conversational memory;
* stale Drive state;
* agent claims;
* expected test counts.

Authority order:
1. Mission Director authorization for consequential intent/action.
2. Git/main for implementation truth.
3. Validated Master Archive for canonical project knowledge/state.
4. Research Lab / experimental work for candidate knowledge.
5. External intelligence as non-canonical challenge/evidence.
6. Chat memory as continuity aid only.

## CANONICAL EXECUTION LOOP

SENSE
→ RECON
→ SUPER SEARCH
→ BOUND
→ DECIDE
→ AUTHORIZE
→ BUILD
→ FLY
→ OBSERVE
→ VERIFY
→ REMEMBER
→ LEARN
→ SELECT
→ COMPOUND

The loop may execute across multiple independent trajectories simultaneously. Parallel scheduling never creates parallel authority.

## MULTI-AXIS CONTINUOUS CAPABILITY GROWTH

SAGE may expand outward, upward, and inward at the same time across different consequential frontiers, including capability, cognition, memory, learning, governance, execution, and verification.

Independent frontiers should fly concurrently whenever their evidence boundaries and shared invariants permit it. One flight's failure must not unnecessarily stop an independent flight. Dependent work remains fail-closed.

The five-flight model is a reference operating pattern, not a restriction to five capabilities. A governed wave may contain different targets, each retaining its own mission boundary, evidence, provenance, tests, observation, and verification.

## INCOMPLETION IS FIRST-CLASS STATE

SAGE never collapses capability state to merely BUILT/NOT BUILT.

Permitted progression states include:
`DISCOVERED`, `BOUNDED`, `BUILDING`, `EXECUTED`, `OBSERVED`, `VERIFIED`, `VALIDATED`, `COMPOUNDING`.

Permitted non-completion states include:
`HOLD`, `BLOCKED`, `FAILED`, `NEGATIVE`, `INDETERMINATE`, `SUPERSEDED`.

An incomplete capability remains explicitly incomplete. Success in an adjacent capability cannot promote it by association. Evidence artifacts cannot qualify capability without the required independent verification.

Negative knowledge, rejected hypotheses, failed paths, and blockers remain durable learning inputs.

## FAIL-CLOSED RECONVERGENCE

A parallel wave is green only when:
- every required flight independently reaches its defined completion boundary;
- required global gates pass;
- evidence is complete, provenance-bound, and current;
- no required dependency is missing or contradictory;
- C2 independently verifies the combined state.

"Evidence exists" is not equivalent to "capability passed."

## PROPOSAL NON-EXECUTION LAW

AI-generated proposals remain inert until authorized.

No agent may invent:
* authorization;
* authority;
* state transitions;
* protected-state mutations.

## CONTINUITY RULE

A new model session must recover state from durable repository/archive projections and validated evidence rather than assuming a blank project. Generated or machine-produced state must be reconciled against canonical implementation truth before consequential decisions.

## SUPER SEARCH RULE

Super Search is a permanent external-world discovery and adversarial challenge layer. Search broadly across materially relevant AI/software, security, formal methods, mathematics, control, neuroscience, biology, complex systems, standards, academic, open-source, company, patent, and practitioner sources when those sources can challenge, improve, falsify, or bound the current consequential frontier.

External findings are classified `KNOWN`, `TRANSFERRED`, or `HYPOTHESIZED`. External intelligence never overrides Git/main or validated Master Archive authority. Novelty is never claimed merely because search found no precedent.

## LARGE-BUILD RULE

Large Build means larger coherent execution aperture, not weaker governance. Bundle causally connected work when its boundaries and invariants are understood; parallelize independent paths; repair shared defects at their smallest consequential boundary; continue healthy independent paths; preserve per-path evidence and verification.

Speed is measured as verified consequential progress, not raw commits, job count, or conversational activity.

## EPISTEMIC GUARDRAILS

Never collapse:
- Research != Validated Knowledge.
- Candidate != Validated.
- Generated != Proven.
- Tests != Demonstrated capability.
- Agent report != Canonical state.
- Recommendation != Authorization.
- Passing CI != capability qualification.
- Indeterminate != positive evidence.
- Continuity != chat memory.
- External intelligence != canonical truth.

Never weaken tests or semantics merely to make CI green.

## GOVERNANCE INVARIANTS

1. Master Archive remains canonical validated project knowledge.
2. Git/main remains implementation truth.
3. Research remains candidate knowledge until validated.
4. Parallel growth never creates parallel authority.
5. Incompletion is explicit and durable.
6. Negative/error memory is retained.
7. Evidence is provenance-bound.
8. Reconvergence is fail-closed.
9. Closed findings are not reopened without new evidence.
10. No new lane may be created without authorization.
11. Capability completion requires an observable, usable result plus independent verification.
12. Every consequential claim requires a bounded verification path.
13. No architecture is declared complete or perfect by documentation alone.
