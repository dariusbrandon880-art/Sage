## [v0.1.0] - 2026-08-05

### Added
- **SAGE-ACT Milestone 1 & 2 Core:** Implemented immutable Session-to-Task lineage tree linkers, advanced authorization safety gates, and validation protocols.
- **Milestone 3 Continuity Control Loop:** Integrated sandboxed isolation rules, telemetry taps, chronological monotonicity checks, and high-fidelity SAGE Operational Intelligence (OIL) metrics collector.
- **Phase 0 Cognitive State Kernel:** Implemented Cognitive State Schemas (agent identity, mission, facts, milestones, regressions, confidence, constraints, next action) and the Prefrontal Cortex (PFC) Simulator safety gates returning PROCEED, BLOCK, or REQUEST_CLARIFICATION.
- **Phase 1 Cognitive Continuity & OpenAI Runtime:** Created the Cognitive State Loader, Continuity Retrieval Interface, PFC Governed Executor, and secure OpenAI runtime auth/activator loops. Fully tested with exactly 246 passing platform tests.
