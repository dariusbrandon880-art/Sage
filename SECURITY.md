# Security Policy

## Supported Versions

Only the latest release on the primary branches is actively supported and maintained.

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |

## Reporting a Vulnerability

The SAGE Development Team is committed to keeping SAGE secure. If you discover a security vulnerability, please report it immediately:

1. **Email:** Please do not publicize vulnerabilities in the issue tracker. Email report details to `security@sage-runtime.org` (hypothetical secure contact).
2. **Details:** Include a clear description of the vulnerability, step-by-step reproduction instructions, and a proof of concept if available.
3. **Response:** We aim to acknowledge security reports within 48 hours and provide a timeline for remediation.

Thank you for helping keep SAGE secure!
