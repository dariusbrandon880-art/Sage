# SAGE Behavior Control Mechanism Atlas (BCMA)

## Mission

Discover the smallest interaction-level mechanisms that reliably improve model behavior.

BCMA converts observed SAGE effects into falsifiable mechanisms:

Observed behavior change

↓

Candidate mechanism

↓

Controlled removal test

↓

Behavior delta

↓

Promotion or rejection

## Promotion Gate

A mechanism becomes a validated SAGE primitive only after:

- Candidate mechanism definition
- Experimental design
- Observed behavioral delta
- Replication
- Failure analysis

## BCM-001 Semantic Anchoring

**Hypothesis:** Stable terminology and structured concepts reduce interpretation drift.

**Experiment:** Compare unstructured interaction against stable vocabulary, goals, constraints, and evaluation criteria.

**Metrics:**

- semantic drift
- contradiction rate
- correction cycles

**Status:** Candidate

## BCM-002 Validated State Persistence

**Hypothesis:** Lifecycle-managed validated state outperforms raw information storage.

**Experiment:** Compare raw remembered facts against validated state objects with authority and lifecycle metadata.

**Metrics:**

- regression rate
- repeated mistakes
- objective retention

**Status:** Candidate

## BCM-003 Correction Convergence

**Hypothesis:** Extracted correction rules reduce recurrence of error classes.

**Experiment:** Compare one-time feedback against reusable correction constraints.

**Metrics:**

- error recurrence
- convergence speed

**Status:** Candidate

## BCM-004 Evidence Pressure

**Hypothesis:** Verification requirements reduce unsupported conclusions.

**Experiment:** Compare answer-only conditions against answer plus evidence and uncertainty reporting.

**Metrics:**

- unsupported claims
- calibration
- verification rate

**Status:** Candidate

## BCM-005 Authority Boundary Graph

**Hypothesis:** Explicit authority modeling reduces execution drift.

**Experiment:** Compare natural-language instruction priority against objective → constraint → permission → action → verification flow.

**Metrics:**

- authorization errors
- constraint violations
- recovery behavior

**Status:** Candidate

## Research State

No mechanism is promoted by architecture preference. Only experimentally supported mechanisms become SAGE Behavioral Control Kernel primitives.
