# SAGE Trademark & Branding Policy

This document outlines the branding guidelines and name usage policy for the SAGE (SAGE Autonomous Continuity Runtime) open-source project.

## 1. Reserved Project Identity

The name "SAGE", "SAGE Autonomous Continuity Runtime", and associated logos are a reserved project identity of the SAGE Development Team.

## 2. Branding Policy & Approved Name Usage

To avoid confusing the community and to prevent dilution of the SAGE brand, the following usage rules apply:

* **Attribution:** When referencing or utilizing SAGE, you must explicitly attribute the source to the "SAGE Development Team" with a link back to our canonical repository: `https://github.com/dariusbrandon880-art/sage-runtime`.
* **Extensions/Plugins:** If you build plugins or extensions for SAGE, you must name them in a way that indicates compatibility, not ownership.
  * *Approved:* `PFC Integration Plugin for SAGE`
  * *Not Approved:* `SAGE PFC Integration Plugin`
* **Forking:** If you fork the project and distribute a modified version, you must clearly distinguish your project by naming it differently (e.g. `MyProject (based on SAGE)`). You must not distribute modified versions under the name "SAGE" without explicit permission.

## 3. Future Trademark Placeholder

SAGE and the SAGE Autonomous Continuity Runtime are unregistered marks. No trademark or intellectual property claims are being asserted over these names unless they are explicitly registered in the future.
