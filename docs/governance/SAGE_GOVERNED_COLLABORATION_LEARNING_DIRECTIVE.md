# SAGE Governed Collaboration Learning Directive

**Status:** Canonical Governance Directive

**Purpose:** Formally codify the principles and promotion pipeline for human-agent collaboration learning, operator preferences, and memory promotion in SAGE.

## Fundamental Distinction Laws

1. **Candidate Pattern ≠ Validated Knowledge ≠ Canonical Truth:** An operator preference, correction, or communication pattern is an observed hypothesis until evidence-scoped falsification tests pass.
2. **The 6-Stage Promotion Pipeline:**
   ```text
   OBSERVED ──> CANDIDATE ──> TESTED ──> VALIDATED ──> PROMOTABLE ──> CANONICAL
   ```
3. **Knowledge Scope Separation:**
   - **PERSONAL:** Specific operator preferences/interaction register.
   - **ORGANIZATIONAL:** Team or station coordination rules.
   - **COLLECTIVE:** Shared multi-session learning hypotheses.
   - **CANONICAL:** Verified platform truth bound to exact evidence.

4. **Automatic Memory Retirement & Falsification:**
   - Temporary statements, jokes, slang, or contradicted operator preferences do not enter canonical knowledge.
   - Contradicted or stale patterns immediately transition to `CONTRADICTED` or `RETIRED` with confidence score `0.0`.
5. **Exact-HEAD SHA Evidence Binding:**
   - Every state transition produces a cryptographically signed `CollaborationMemoryReceipt` containing `exact_head_sha` and `receipt_hash`.
