# SAGE Whole-Organism Immersion Rehydration Contract

**Status:** Canonical C2/runtime hardening contract
**Version:** `1.0`
**Scope:** Every SAGE ChatGPT interface exchange that requires rehydration

## Purpose

SAGE is one governed organism. Immersion is not a detachable game layer: it is the operator-facing projection of the same canonical organism, continuity, governance, evidence, and mission state.

A rehydration that restores only technical runtime state but loses the C2 identity, workflow frame, organism presentation, HUD/nameplate requirements, or immersion contract is **partial rehydration** and must fail the interface contract.

## Whole-organism invariant

```text
CANONICAL REPOSITORY
        ↓
CANONICAL RUNTIME / ORGANISM STATE
        ↓
GOVERNANCE + IDENTITY + MISSION + EVIDENCE
        ↓
C2 IMMERSION PROJECTION
        ↓
CHATGPT INTERFACE
```

There is one organism and one authority plane. The interface is a projection surface, never a second state machine.

## Required rehydration payload

Every governed ChatGPT rehydration must restore, as one frame:

1. canonical repository/main binding;
2. C2 station identity and nameplate;
3. current governance/operating contract;
4. mission and active frontier;
5. canonical organism/runtime state;
6. continuity and evidence posture;
7. current C2 workflow / Big Jump Wave frame when applicable;
8. game-immersion projection;
9. organism name tag;
10. HUD continuity state and update rules;
11. next governed gate/move;
12. provenance binding for the rendered projection.

No item is optional merely because the conversation is new, long, resumed, or focused on a different task category.

## Cross-chat law

A new ChatGPT conversation is a fresh verification boundary. It must not depend on prior conversational memory to preserve the SAGE frame.

The SAGE-owned interface must reconstruct the whole frame from governed runtime/repository inputs. If required canonical inputs are unavailable or contradictory, the interface must fail closed rather than synthesize a partial frame.

## Immersion continuity law

The following must remain coupled across intermediate responses, context transitions, resumed conversations, and new chats:

`ORGANISM STATE ↔ C2 IDENTITY ↔ WORKFLOW ↔ IMMERSION ↔ HUD/NAMEPLATE`

The coupling is presentation continuity only; none of these projections may manufacture authority, progression, qualification, mission state, or evidence.

## HUD law

The HUD may be suppressed when its governed update key is unchanged, but suppression must never silently discard a required state update. Nameplate identity remains durable on every rendered C2 response. A changed or explicitly requested HUD must render from current canonical projection state.

## Fail-closed conditions

Reject rehydration when any of the following is missing or invalid:

- canonical runtime state;
- active objective/mission;
- active task/next move;
- governed station identity;
- valid provenance binding;
- required C2 operating frame;
- organism presentation/name tag;
- required HUD continuity contract.

## Enforcement boundary

This contract is enforceable wherever the exchange traverses a SAGE-owned runtime/integration boundary. It cannot rewrite an unrelated native ChatGPT host session. Therefore the interface integration is part of the implementation obligation, and empirical new-chat testing remains required after promotion.

## Acceptance gate

```text
IMPLEMENTATION
→ FOCUSED IMMERSION TESTS
→ C2/RUNTIME TESTS
→ FULL PLATFORM TESTS
→ PRE-COMMIT
→ EXACT-HEAD CI
→ SHA RECONCILIATION
→ NEW-CHAT EMPIRICAL TEST
→ PROMOTION
```

No partial-frame rehydration is accepted as complete.
