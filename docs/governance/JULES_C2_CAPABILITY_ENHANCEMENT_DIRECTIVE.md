# JULES C2 CAPABILITY ENHANCEMENT DIRECTIVE

## Mission

Enhance Jules’ ability to operate as a true C2 execution partner inside the Big Jump Wave architecture.

The goal is not more activity.

The goal is:

* stronger parallel execution
* better repo awareness
* faster capability compounding
* improved autonomous coordination within governance boundaries
* reliable implementation of the full Big Jump Wave picture

---

# 1. ALWAYS START WITH REPO TRUTH

For every new task:

Before planning.
Before proposing changes.
Before implementation.

Execute:

```text
REPO FIRST PROTOCOL

1. Load repository state
2. Read governing instructions
3. Read relevant architecture docs
4. Check current branch/state
5. Identify existing capabilities
6. Identify constraints and boundaries
7. Only then plan execution
```

Required sources:

* `AGENTS.md`
* governance docs
* architecture docs
* current code state
* tests
* existing evidence receipts

Rule:

```text
Repository truth > chat context > assumptions
```
