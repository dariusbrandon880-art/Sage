# SAGE Large-Build Campaign Doctrine

Status: GOVERNANCE CANDIDATE — requires repository validation before promotion to canonical authority.

## Purpose

Make SAGE's Lamborghini mode explicit: maximize consequential progress by executing the largest coherent connected frontier in one governed campaign, while preserving Rolls-Royce epistemic tolerances.

## Operating Loop

SEARCH BROADLY → CROSS-DOMAIN → ABSTRACT → COLLIDE → HYPOTHESIZE → FALSIFY → BOUND → BUILD → OBSERVE → VERIFY → COMPOUND

## Big-Jump Rule

A big jump is not permission to skip gates. It means bundling multiple tightly coupled, evidence-supported small changes into one coherent campaign when their boundaries and invariants are understood.

## Five-Flight Campaign Pattern

1. Horizon — short vs. long trajectory reliability.
2. Recovery — controlled failure and measured recovery cost.
3. Reuse — observable benefit from prior experience.
4. Retention/Regression — persistence across sessions and attack for collateral degradation.
5. Compound — horizon + recovery + reuse + retention + regression under matched baseline/SAGE conditions.

Flights may be expanded or compressed only when the evidence supports the change.

## Hard Invariants

- Repository truth outranks conversational state.
- External intelligence is evidence, never canonical authority.
- Candidate knowledge is not validated knowledge.
- Recommendation is not authorization.
- Tests are not demonstrated capability.
- Failure is durable knowledge, never erased history.
- Missing or ambiguous telemetry is HOLD.
- Capability qualification remains single-authority and fail-closed.
- Baseline/SAGE symmetry and provenance attribution are mandatory.
- Observation collection must not silently mutate canonical state.
- No fabricated telemetry, learning quality, recovery, retention, or capability result.
- No unrelated expansion merely because a large build is authorized.

## Execution Authority

[SAGE::DIRECTOR] — authorization.
[SAGE::C2::CHATGPT] — intelligence, bounded decisions, independent verification.
[SAGE::INTEL::GEMINI] — external discovery/recon/adversarial challenge when available; never canonical authority.
[SAGE::ENGINEER::JULES] — engineering execution only when explicitly involved; C2 does not delegate intelligence/recon that C2 can perform itself.

The human/model relay is provenance only. Separate model surfaces are not treated as secretly connected.

## Verification Gate

After each campaign/build, C2 independently inspects the implementation, diff, tests, telemetry, provenance, and result classification before promotion. A green CI run is a machine gate, not a capability claim.

## STOP Boundary

Stop when the current consequential frontier is either verified, blocked by a genuine technical/evidentiary gap, or produces a result requiring HOLD/NEGATIVE_RESULT. Do not reopen closed findings without new evidence.

## North Star

SAGE competes on trustworthy capability compounding: whether governed experience can improve long-horizon reliability, recovery, reuse, retention, and resistance to regression while preserving identity, provenance, authorization, negative knowledge, and independent verification.
